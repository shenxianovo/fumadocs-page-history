---
title: Display & language
description: Adjust history presentation, translated labels, and date formatting.
---

Use `display` settings to change the history's appearance. For Chinese, configure both translated interface labels and date formatting. These settings apply after the [minimal installation](/docs); the [Demo](/docs/demo#history-and-contributors) lets you try them before editing your site.

## Display options

Set `display` in plugin settings, or pass these props to `GitChangelog`:

```ts
const display = {
  locale: 'zh-CN',
  defaultExpanded: true,
  commitsRelativeTime: true,
};
```

| Setting                                         | Default   | Effect                                                 |
| ----------------------------------------------- | --------- | ------------------------------------------------------ |
| `locale`                                        | `en`      | Date formatting and localized contributor names.       |
| `defaultExpanded`                               | `false`   | Show the timeline on initial render.                   |
| `commitsRelativeTime`                           | `false`   | Relative dates for commit rows.                        |
| `showContributors`                              | `true`    | Show contributors above the timeline.                  |
| `hideChangelogHeader`, `hideContributorsHeader` | `false`   | Hide section headings and their TOC entries.           |
| `hideChangelogNoChangesText`                    | `false`   | Hide an empty-history message in manually rendered UI. |
| `hideSortBy`                                    | `false`   | Hide the sorting button.                               |
| `displayAuthorsInsideCommitLine`                | `false`   | Add avatars beside each commit.                        |
| `numCommitHashLetters`                          | `7`       | Short commit hash length.                              |
| `id`, `contributorsId`                          | Automatic | Override the section anchors.                          |
| `className`                                     | —         | Add wrapper classes.                                   |

`locale` controls dates and contributor names. Interface labels use the site's translation provider; configure both with the [single-language setup](#single-language-site) below.

Visible section headings appear in **On this page**. Automatic anchors avoid existing headings. Multiple manual instances need distinct IDs; a custom `id` gives contributors the default anchor `<id>-contributors`. Screens up to 640px hide commit hashes to leave space for messages.

## Single-language site

Keep the minimal plugin setup and add `display.locale`:

```ts title="source.config.ts"
import { defineConfig } from 'fumadocs-mdx/config';
import { remarkGitChangelog } from 'fumadocs-page-history/remark';

export default defineConfig({
  mdxOptions: {
    remarkPlugins: [
      [
        remarkGitChangelog,
        {
          repository: { url: 'https://github.com/owner/repository' },
          display: { locale: 'zh-CN' },
        },
      ],
    ],
  },
});
```

Register both the Fumadocs and Page History translation keys. Alias the package preset when your site uses presets from other packages:

```ts title="lib/translations.ts"
import { defineTranslations } from 'fumadocs-core/i18n';
import { uiTranslations } from 'fumadocs-ui/i18n';
import { gitChangelogTranslations, zhCN as historyZhCN } from 'fumadocs-page-history/i18n';

export const translations = defineTranslations()
  .extend(uiTranslations())
  .extend(gitChangelogTranslations())
  .preset(historyZhCN());
```

Keep your existing Fumadocs label translations and other package presets in this chain. Page History's preset supplies its own labels only.

Pass the translations to your existing root provider:

```tsx title="app/layout.tsx"
import { RootProvider } from 'fumadocs-ui/provider/next';
import { i18nProvider } from 'fumadocs-ui/i18n';
import { translations } from '@/lib/translations';

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="zh-CN" suppressHydrationWarning>
      <body>
        <RootProvider i18n={i18nProvider(translations)}>{children}</RootProvider>
      </body>
    </html>
  );
}
```

Keep your existing CSS imports and theme configuration. The stylesheet still needs the import from [Setup](/docs#import-the-styles).

## Multi-language site

Add the keys and preset to your existing Fumadocs i18n configuration:

```ts
const translations = i18n
  .translations()
  .extend(uiTranslations())
  .extend(gitChangelogTranslations())
  .preset('zh', historyZhCN());
```

Here `zh` is the route-language key in your site's `i18n` configuration. Pass the active route language when constructing its provider. Register the compiler plugin in each localized collection with its corresponding `display.locale`, such as `en` or `zh-CN`.

For a manually rendered `GitChangelog`, pass `locale` for the current page. The [interactive demo](/docs/demo) shows English and Chinese labels and dates.

## Time zones

The reader's browser time zone is detected automatically. Server HTML and the initial client render use UTC; mounted pages use the browser zone. A date near midnight may change after hydration. This happens independently of the page language, with no time-zone configuration.
