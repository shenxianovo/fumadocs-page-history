## History and contributors

Choose an **Example** or adjust **Preview options**. Expand and sort the timeline, switch languages, and use the site's theme switch to try light and dark mode.

<ChangelogDemo />

**Reset** restores the selected example. **Language** changes both labels and dates. **Start expanded** sets the initial open state; the timeline can also be opened directly. To use these settings in your site, see [Display & language](/docs/localization).

The preview uses a saved snapshot of [this project's Git history](https://github.com/shenxianovo/fumadocs-page-history/commits/main/docs/content/docs/index.mdx), with [shenxianovo's GitHub profile](https://github.com/shenxianovo). The **Co-authors** example adds an illustrative author with a longer name and no avatar.

## Inline workspace changes

Select **Change example** to explore paragraph edits, Chinese word boundaries, table rows, and link destinations. Removed content is red and added content is green. In a full rewrite, each paragraph has a light background and the changed words have stronger highlights.

<WorkspaceDemo />

These fixed sample documents use the package's actual comparison and rendering components. They do not read a visitor's checkout or require GitHub access.

## Try your own documents

Follow the [Workspace changes guide](/docs/workspace-changes) to enable local comparison in your site.

To try this repository locally, run `pnpm docs-dev` and edit a phrase in [Configuration reference](/docs/configuration) or another document. Save to update the content; stage or commit to see how the markers respond. Git-only changes refresh within three seconds. In development, this page's own source edits are highlighted too; the interactive examples continue to use their saved sources.

Live checkout comparisons run only in local development. Production documents keep their normal appearance, while the saved examples above remain interactive.
