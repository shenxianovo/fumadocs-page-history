Choose an **Example** or adjust the controls below the preview. Expand and sort the history, switch languages, and use the site's theme switch to try light and dark mode.

<ChangelogDemo />

**Language** changes both labels and dates. **Start expanded** sets the initial open state; you can also open and close the history directly in the preview. **Empty history** shows the empty state, while disabling both sections hides them. **Reset** restores the selected example, including its expansion and sort order.

The preview uses a saved snapshot of [this project's Git history](https://github.com/shenxianovo/fumadocs-page-history/commits/main/docs/content/docs/index.mdx), with [shenxianovo's GitHub profile](https://github.com/shenxianovo). The **Co-authors** example adds an illustrative author with a longer name and no avatar. No GitHub token is needed to view it.

## Inline workspace changes

Try these saved examples on this site, including the published version. Select **Change example** to see paragraph edits, Chinese word boundaries, table rows, and link destinations. The preview uses the package's actual comparison and rendering components with fixed sample documents.

## Try your own documents

When running this site locally with `pnpm docs-dev`, edit a phrase in [Configuration](/docs/configuration) or another document. The normal page keeps shared text once and shows only removed words in red and added words in green. Adding a table row highlights just the new row. Save another edit to update the rendered content; stage or commit it to check how the markers respond. Pure Git changes refresh within three seconds. This Demo page uses only the saved examples so its own source edits do not obscure the preview.

Live comparison with your checkout is available only in local development. Production documents keep their normal appearance; the saved examples above remain interactive. See [inline workspace changes](/docs/configuration#inline-workspace-changes) for integration details.
