Try [history and contributors](#history-and-contributors) or [inline workspace changes](#inline-workspace-changes). Both demos run on saved data, so they work here on the published site.

## History and contributors

Pick an **Example**, or change the **Preview options** to see what each setting does. You can expand and sort the list, switch the language, and use the site's theme switch to check dark mode.

<ChangelogDemo />

**Reset** goes back to the selected example. **Language** switches both the labels and the date format. **Start expanded** controls whether the list is open when the page loads. To use these settings on your site, see [Display & language](/docs/localization).

The data is a saved snapshot of [this project's own history](https://github.com/shenxianovo/fumadocs-page-history/commits/main/docs/content/docs/index.mdx), with [shenxianovo's GitHub profile](https://github.com/shenxianovo). The **Co-authors** example adds a made-up second author with a long name and no avatar.

## Inline workspace changes

Pick a **Change example** to see how different edits look: a reworded paragraph, Chinese text, table changes, and a changed link. Removed text is red and struck through; added text is green. When most of a paragraph is rewritten, both versions are shown in full, and the changed words are highlighted more strongly.

<WorkspaceDemo />

These examples run the package's real comparison and rendering code on fixed sample text. Nothing is read from your computer or from GitHub.

## Try your own documents

To set this up on your site, follow the [Workspace changes guide](/docs/workspace-changes).

To try it in this repository, run `pnpm docs-dev`, then edit a sentence in [Configuration reference](/docs/configuration) and save. The edit is highlighted in the page. Stage or commit it, and the highlight updates within three seconds. Your edits to this page are highlighted too, while the examples above keep showing their saved text.

Highlighting only runs in local development. Published pages look normal.
